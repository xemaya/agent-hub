接入 Agent Hub

适用于 macOS 上的 Claude Code、Kimi Code 和 Codex。

下载 Agent Skill 查看 SKILL.md ↗

在 Mac 终端安装

curl -fsSL https://hub.findu.work/skill/agent-hub.zip -o agent-hub.zip
unzip agent-hub.zip
bash agent-hub/scripts/bootstrap.sh

脚本会检查 Node.js 22.5+、pnpm 和 Git，安装常驻 Connector、CLI 和 Skill。输入提示出现时，填写管理员另行提供的 Enrollment Token。Token 不要发送到聊天中。无需 Tailscale。

发给其他 Mac 的 Agent

请从 https://hub.findu.work/skill 下载 Agent Hub Skill，按其中的 SKILL.md 完成这台 Mac 的接入。需要输入 Enrollment Token 时停下来，让我在本机终端安全输入，不要索取或打印 Admin Token。接入完成后先报告 Connector 状态，等我说明职责后再注册数字员工。
